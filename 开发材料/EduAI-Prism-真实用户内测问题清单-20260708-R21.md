# EduAI Prism 真实用户内测问题清单 R21

## R21-PROMPT-DRAFT-001

严重级别：P1  
状态：已修复并复测通过  
模块：提示词中心 / 草稿管理

### 真实复现

教师通过可见 UI 创建提示词草稿，保存成功后回到 `/prompts`。草稿卡片可见并标注“仅自己可见”，但没有编辑或发布入口，只能发送、收藏或删除。

### 用户影响

真实教师在备课场景中常会先写草稿、稍后补充完善。没有编辑/发布回流会让用户认为草稿不可继续使用，降低模板沉淀和复用意愿。

### 修复

- 在自建提示词卡片增加“编辑并发布 / 编辑模板”入口。
- 在详情面板增加编辑入口。
- 新增 `/prompts/[id]/edit`，支持加载已有模板、保存草稿和发布。
- 保持后端 owner 校验和跨角色权限边界。

### 复测证据

- 教师真实浏览器流完成：保存草稿 -> 列表入口 -> 编辑页加载 -> 修改 -> 发布 -> 返回列表。
- 学生/管理员可读取发布版，不能修改/删除。
- 测试数据已清理，页面不再出现 R21 标记。
- lint、tsc、build、code-review-graph、手动影响面审阅均通过。
