# 教学资源与 HTML 活动

## 前端闭环与双部署路线 · V2

日期：2026-09-08。本轮以当前工作区为基线增量开发，不回退其他模块。适用教师、教研员和学生。

> **本轮边界：**真实本机上传、保存、预览、运行和离线活动包交付；未接通学校资源服务器、在线发送、班级收件、成绩提交。界面不会把本机操作显示为云端成功。是否接通真实后端的澄清尚未收到，本轮继续遵守“后端先不接通”。

### 1. 入口与页面

| 用户 | 入口 | 页面职责 |
| --- | --- | --- |
| 教师、教研员 | 左侧“教学 → 校内资源库”，知识库内同名入口 | 整理文件、查看原始资料、运行 HTML、编写布置草稿、导出活动包 |
| 学生 | 左侧“项目 → 学习资源”；首页“打开学习资源”；项目活动页“打开课堂文件与 HTML 活动” | 打开教师提供的活动包或文件，在窗口内使用，记录观察并导出学习记录 |
| 非授权角色 | 服务端路由守卫 | 教师库仅教师/教研员；学生资源页仅学生，不能通过隐藏导航代替鉴权 |

教师路径：`/knowledge/resources`。学生路径：`/student/resources`。原有 `/student/activities` 项目发布、提交、批阅接口保持独立，不挪作文件分发接口。

**侧栏修复：**外壳占视口高度，顶部品牌和底部账户不收缩；中间导航使用 `min-h-0 flex-1 overflow-y-auto`。展开、全收起、混合分组、图标坞和调整宽度均保持账户贴底。空白留在可伸缩导航区，而不是把账户向上推；菜单较长时只滚动导航。

### 2. 文件能力矩阵

| 格式 | 本轮保存与使用 | 不能误称的能力 |
| --- | --- | --- |
| PPTX | 原字节保存/下载；按 presentation 关系顺序逐页提取文字 | 不还原幻灯片版式、图片、动画和嵌入对象 |
| DOCX | 原字节保存/下载；本机文字预览 | 不是 Word 原版排版或协作编辑 |
| PDF | 原字节保存/下载；分页文字预览 | 不含扫描件 OCR、原版图片/图表；加密文件提示限制 |
| PPT、DOC | 保存和下载原文件 | 不伪造在线预览结果 |
| PNG、JPEG、WebP | 实际解码显示，加载失败有提示 | 不支持将 SVG 当作安全图片执行 |
| MP4、WebM | 浏览器原生视频控件，用户点击播放 | 编码能否播放取决于浏览器；不自动播放 |
| MP3、WAV、OGG、M4A | 原生音频控件，错误/超时提示 | 不把已读取元数据当成播放完成 |
| TXT、MD | 转义文本显示，最多前 20 KB | 不执行 Markdown 内的 HTML/脚本 |
| HTML、HTM | UTF-8 单文件隔离运行，开始、重新开始、停止、扩大预览区 | 不承诺任意联网网页、框架工程目录或外链依赖均兼容 |
| `.eduactivity` | 学生导入任务说明与原始 HTML，校验文件摘要 | 不是服务器签名，不证明发件教师身份 |

上传限制：每批最多 5 个文件、合计 100 MB；单文件 50 MB，HTML 5 MB；每账号浏览器草稿总量 200 MB。活动包导入上限 8 MB。

文档预览另有更严格预算：文档 10 MB；Office 最多 512 个压缩条目，总解压量 32 MB，单条目 8 MB、XML 2 MB；最多 30 页、20 万字符。图片/视频分辨率限制 2400 万像素，解析/加载超时 15 秒。这些是应用预算，不是浏览器进程级 CPU/内存硬隔离。

### 3. 实际闭环

```text
教师选择原文件
  → 格式/容量校验 → SHA-256 → IndexedDB 事务完成
  → 本机草稿 → 预览并亲自验证内容
  → HTML 活动 + 适用对象 + 活动任务 + 观察问题
  → 保存布置草稿 / 导出 .eduactivity
  → 通过学校已有渠道人工分发
  → 学生“学习资源”导入 → 字段/大小/摘要校验
  → 明确来源未验证 → 主动开始 → 隔离窗口实际交互
  → 学生自行填写观察和疑问 → 保存本机笔记
  → 导出带资源摘要、活动包 ID 和记录时间的学习记录
  → 教师通过已有渠道收取、核对；尚未自动在线提交
```

课堂示例选择“同一个整体的 1/2 与 2/4 比较”。按钮操作改变涂色与分数显示，学生用观察解释等值关系；不以点击次数、停留时长或虚构积分替代学习证据。内置示例始终标注为示例，不能混作学校已经发布的任务。

活动包保留原始 HTML 字节，正文以 Base64 携带；SHA-256 验证传输一致性。**摘要只能检测内容不一致，不能确认作者身份或整份任务说明的可信性。**导入者仍须确认文件来源。

学生笔记只采集自行填写的观察、疑问、对应资源摘要、活动包 ID 和本机时间；按账号、资源摘要与活动包分区，同一 HTML 的不同活动包不串用笔记。旧版笔记只在资源与活动包都匹配时恢复。不收集摄像头、麦克风、学生名单或环境行为。笔记不是成绩，不自动进入成长档案。不生成“掌握程度”“已完成课程”等无依据结论。

未保存笔记时，关闭材料、点击当前页或侧栏导航链接、刷新/关闭浏览器均有提醒；浏览器可能限制原生离开提示，移动系统强制关闭、崩溃与单页历史跳转不承诺保留未保存文字。已保存笔记可以重新导入对应文件/活动包恢复。

### 4. 交互规则

| 控件 | 真实动作 | 失败或边界状态 |
| --- | --- | --- |
| 上传资源 / 选择文件 | 文件选择、拖拽、多文件队列 | 不支持、空文件、超限、重复内容分别提示 |
| 保存本机草稿 | 等待 IndexedDB 完成 | 事务中止不关窗口、不显示保存成功，可重试 |
| 查看 | 对应格式预览 | 解码失败、无可提取文字、超时明确显示 |
| 开始活动 | 检查真实 CSP 响应头，再读取 HTML 和挂载隔离窗口 | 安全头缺失、UTF-8 错误、脚本错误和加载超时均不冒充通过 |
| 重新开始 / 停止 | 新运行会话 / 卸载运行区，清除本次状态 | 不等于结束学习或提交成绩 |
| 分享给学生 | 展开适用对象、任务与观察问题表单 | 在线发送未接入，不显示班级已送达 |
| 保存布置草稿 | 账号、资源版本隔离的本机写入 | 缺少必要字段、存储不可用、未保存关闭有反馈 |
| 导出活动包 | 生成可被学生端真实导入的文件 | 等待文件读取与摘要完成；关闭后不延迟触发下载 |
| 打开教师给的文件 | 本机读取/活动包校验，默认不持久化原文件 | 校验失败不启动活动，不读取其他账号草稿 |
| 学生下载原文件 | 生成所选材料的真实原字节文件 | HTML 下载后离开平台隔离保护；失败清理旧成功提示 |
| 保存笔记 / 导出学习记录 | 本机记录、真实生成下载文件 | 空观察不自动补写；保存失败不声称已提交 |

教师库沿用现有青绿色工作区基调、紧凑表格和侧栏。资源类型扩展到课件、教案、学习单、互动活动、音视频、其他资料六类；没有另做营销首页。新图形为 GPT 生成的实体材质图标，实际命令保持 Lucide 图标、可访问名称和原生按钮，文字不烘焙进图片。

桌面使用有明确标题、关闭入口、独立滚动内容与固定操作区的窗口；移动端沿用页面布局，并为学生底部快捷栏和安全求助入口预留滚动空间。主题和减少动画偏好沿用既有系统。

### 5. HTML 运行安全

结构为“应用页面 → 可信静态运行壳 → 不可信 HTML Blob”。两个 iframe 均只启用 `sandbox="allow-scripts"`，不启用 `allow-same-origin`、表单、下载、弹窗或顶层导航权限。上传内容从不注入宿主 DOM。

`/resource-runtime.html` 使用真实响应头 CSP，外层 `frame-src blob:`；内层额外设置 `frame-src 'none'`、`connect-src 'none'`、`object-src 'none'`、`worker-src 'none'`、`base-uri 'none'` 和 `form-action 'none'`。外层策略限制内部导航，不能只依赖上传文件自己声明的 meta。Blob 继承创建环境的 CSP。[W3C CSP](https://www.w3.org/TR/CSP3/#security-inherit-csp)

每次启动使用随机会话 token；双方检查消息窗口来源与消息版本，外层只初始化一次，并按 UTF-8 字节限制内容。启动前只接受约定的 13 项 CSP 指令和值，拒绝重复指令以及未经审查的覆盖指令，例如 `script-src-elem`。宿主只接收有限的运行状态，不提供导航、取文件、读账号、写成绩等 RPC。来自活动的分数/完成事件不可信。iframe 的 load 事件本身不代表内容正确，因此不会据此生成学习评价。[MDN iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)

支持内联 CSS/JS 和嵌入的 data/Blob 媒体；外部 CDN、相对目录素材、登录、fetch、Worker、WASM 等不在本轮兼容范围。不会为了让某个文件运行而扩大权限。原始 HTML 下载后离开平台沙箱，不提供运行 Blob 的新标签页按钮。

**剩余风险：**浏览器沙箱不是反病毒或内容审核，也不是 CPU/内存硬配额；WebRTC 等网络侧信道与跨浏览器一致性未形成完整保证。恶意死循环可能阻塞标签页，“停止”只在页面仍能响应时有效。互联网发布必须额外经过隔离站点、扫描、内容审核与浏览器兼容验收。

Office 预览用 Mammoth 的纯文本提取，结果由 React 转义；不把转换 HTML 注入主页面。压缩包路径、条目/解压预算、XML 实体与结构限制在解析前/流式读取中检查。[Mammoth 安全说明](https://github.com/mwilliamson/mammoth.js#security)

### 7. 本地学校服务器路线

建议复用 Next 应用与现有身份入口，新增以下**未来**模块，非本轮已部署：

1. 学校/成员关系、任教班级和教研组关联：学校 ID 由服务器当前身份与成员关系确定。
2. 私有原文件存储：学校服务器独立目录或 S3 兼容存储，禁止直接放 `public`。元数据可在小规模试点使用既有数据库方案；多人并发、备份与后续互联网统一时推荐 PostgreSQL。
3. 预览队列：隔离工作进程运行 LibreOffice/PDF 转换，禁外网，限制时间/内存/解压量；OCR 单独排队并标注识别结果，原文件不覆盖。
4. 校园 DNS 与 HTTPS：校内颁发且受设备信任的证书；localhost 开发不等于普通校园 IP 的 HTTP 访问。Web Crypto 等能力依赖安全上下文，不要求用户绕过证书警告。
5. 不可信活动独立站点：如主应用 `school.example.edu` 与隔离活动站点 `school-activities.example.net`，不共享认证 Cookie；不能仅靠另一个端口宣称进程隔离。
6. 定期备份元数据和私有文件的一致快照、恢复演练、磁盘配额与可用空间告警。学生离线记录不承诺自动同步，待身份和版本校验后再导入。

断网时，已经登录的缓存页面与本机文件是否还能用须另做离线验收；本轮不是 PWA，不宣称无网络也能首次打开整个应用。

### 8. 互联网部署路线

Next 应用 + PostgreSQL + 私有对象存储 + 可撤销的授权记录 + 异步预览工作进程；静态隔离活动站点使用独立域名/站点与严格响应头。资源 URL 不含长期密钥，签名下载凭据短时有效且日志脱敏。CDN 不能把私有资料按公共缓存分享给其他学校。

核心对象：`SchoolMembership`、`TeachingMembership`、`Resource`、不可变 `ResourceVersion`、`PreviewJob`、`ResourceGrant`、`ActivityAssignment`、`StudentSubmission`、`TeacherReview`、`AuditEvent`。

| 未来 API | 权限与状态约束 |
| --- | --- |
| `POST /api/school-resources/uploads` | 验证学校成员与配额，返回上传会话；校验真实文件类型，完成后服务器计算摘要 |
| `GET /api/school-resources` | 仅当前学校授权资源，默认私有，不以客户端 scope 决定访问 |
| `GET /api/school-resources/:id/versions/:version/file` | GET/HEAD/Range 同样鉴权；原文件 attachment + nosniff |
| `POST /api/school-resources/:id/publish` | 授权角色审核，绑定不可变版本与可见范围；幂等键防重复 |
| `POST /api/activity-assignments` | 绑定资源版本/摘要、当前教师任教范围及接收者；不信任客户端班级列表 |
| `GET /api/student/activity-assignments` | 当前学生实际获得授权的任务，提供撤回/过期状态 |
| `POST /api/activity-assignments/:id/submissions` | 当前学生、对应版本与截止规则；服务端判定状态，不能接受活动 iframe 自报成绩为权威 |
| `POST /api/submissions/:id/review` | 任教教师核对观察和证据，才关联成长档案；记录来源和版本 |

发送后以服务器返回的 assignment ID、版本、收件范围和状态呈现“已布置”；不能用前端计时器伪造成功。撤回后禁止新访问，但已经下载的文件无法技术性收回。资源编辑产生新版本，原任务仍指向旧版本，避免学生和教师看到不同题目。

HTML 成果采集如需后续接入，必须采用受限 schema、服务端验证和教师复核；学生可选择不提交私人草稿，不公开排名，不将活跃时长包装为能力结论。
