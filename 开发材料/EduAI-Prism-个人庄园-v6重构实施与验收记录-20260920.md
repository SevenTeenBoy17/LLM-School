## 1. 结论先行

本轮交付的是**已实现并完成本地验证的重构候选版本，不是 v6 全部范围的正式验收通过版**。

主场景、真实地块操作、学习任务状态、反思保存、执行复习、表达证据修订、教师审核回流、成果入册、档案来源返回均已接入现有后端。没有将 Mock 原型、截图效果或 HTTP 200 单独当作业务成功。

仍未交付：教师可视化发布/分层分派课程任务；土地扩建规则和审批；统一跨模块任务资源版本；学校现场教学验证及校内/公网部署演练。正式 CodeRabbit 和 Supervisor 验收缺少有效结果，终态不得写为 complete。

## 2. 可以直接使用的链路

```text
学习任务 -> 作答与反馈 -> 反思保存 -> 安排复习 -> 本次总结
               |                           |
               v                           v
          可用成长授权                  到期变式复习
               |
               v
       可选照料 -> 作物成长 -> 收获入仓

创作草稿 -> 提交老师 -> 退回意见 -> 原证据修订 -> 老师接受
                                                   |
                                                   v
                              个人庄园成果 <-> 成长档案袋
```

- 作答正确不再直接等同于完成本次学习，更不等同于长期掌握。
- 草稿、反思、复习与作品保存免费，不扣成长能量。
- 照料每次消耗 8 点符合用途的成长授权；多笔授权可以组合，积分与能量分账。
- 审核、版本、授权用途和操作幂等由服务器校验，不由页面宣称。
- 未知提交结果先查询原操作回执；重新登录后保留原操作编号及原内容，避免再次扣减。
- 跨天重新开始需要显式操作；旧任务和反思保留只读历史，不通过读取接口悄悄重置。
- 没有付费、抽奖、偷取、个人成绩排行；答错不让植物生病，结束学习后保留只读查看。

## 6. 审阅与修复

独立角色发现并推动修复：

1. 复制内容可能冒充已审核成果：只允许标准表达成果、对应审核和确切版本入册。
2. 老师换班后旧操作回执可能越权：回放前重新检查当前班级权限。
3. 未知提交在重新登录后丢失操作标识：保留原标识、请求内容并先查回执。
4. 完成后的任务跨天无法再开始：明确新任务操作，历史只读保留。
5. 历史学习来源可能打开当前任务：按确切 evidenceId 展示，非法来源不回退冒充。
6. 地块按钮矩形互相覆盖：分离菱形命中层，并实际点击所有地块内部点。
7. 档案有数据但没有来源入口：增加版本和返回庄园成果的真实链接。

人工独立代码/测试完整性审阅对上述限定差异给出 APPROVE。**这不是 CodeRabbit 正式审阅记录，也不是 Supervisor 门禁通过。**

CodeRabbit CLI 两次未进入实际审阅，错误为 `Unable to determine base branch`。第二次指定修改前提交仍发生该错误；按失败次数限制停止，不把无输出当零问题。后续应在审阅副本配置正确的基准分支后重新运行，避免将整个脏工作区上传。

Supervisor 的正式 typecheck、review 和 test-integrity 请求在适配器中失败，返回 `gate-adapter-failure` 或 `gate-event-invalid-state`；原生规划工具本会话不可用。已采用用户授权的官方 CLI 规划路径，但它不替代独立执行门禁。最终记录以 Supervisor 原始报告为准，缺失项继续是 MISSING。

## 8. 校内与公网部署边界

本轮沿用 Next.js/React/TypeScript、服务端 SQLite、现有会话和权限，不增加依赖云端生成能力。静态美术本地提供，庄园主链测试没有外网资源请求。

| 场景 | 建议实施路线 | 本轮状态 |
|---|---|---|
| 学校内网 | 单服务实例、持久化数据目录、受控反向代理、校内 HTTPS、同源 API、统一北京时间学习日 | 本地构建/隔离测试，不等同学校服务器部署 |
| 公网单校试点 | HTTPS、安全 Cookie、限制文件访问、日志脱敏、备份恢复、更新维护窗口 | 未部署、未进行公网压测 |
| 多校规模化 | 明确租户边界、学校管理员权限、数据库与对象存储隔离评估，再做多实例设计 | 未实现多租户重构，不能以 classId 当完整学校隔离证明 |

禁止将测试数据库、测试登录信息、原始学生作答和运行密钥放进公开发布包。SQLite 备份必须使用一致性备份方式，不能在线只复制主数据库而漏掉 WAL。
