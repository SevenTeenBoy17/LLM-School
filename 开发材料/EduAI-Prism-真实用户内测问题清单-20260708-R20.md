## 已修复问题

### R20-PROMPT-GOV-001 暂存草稿被公开发布

严重级别：P1  
状态：已修复并复测通过

现象：

- 教师点击“暂存草稿”后，提示词实际保存为 `pub`。
- 学生和管理员均可在提示词列表中看到该“草稿”。
- 学生和管理员可读取草稿详情。

影响：

- 教师未完成的备课模板可能提前暴露给学生或管理端。
- “暂存草稿”与真实行为不一致，降低教师对产品的信任。

解决：

- 新建提示词支持 `draft/pub` 状态。
- 暂存写入 `draft`，发布写入 `pub`。
- 列表和详情 API 对非创建者隐藏草稿。
- 非创建者访问草稿 mutation 路由返回 404。
- UI 增加“草稿 / 仅自己可见”提示。

复测：

- 教师草稿：仅教师可见。
- 学生/管理员列表：不可见草稿。
- 学生/管理员草稿详情：404。
- 学生/管理员草稿修改/删除：404。
- 已发布模板：学生/管理员可见，使用计数正常递增。
- 非创建者修改/删除已发布模板：403。
- 临时数据清理后，三类角色列表均无 R20 残留。

证据：

- `r20-draft-leak-baseline.json`
- `r20-postfix-api-governance.json`
- `r20-postfix-published-governance.json`
- `r20-final-cleanup-sweep.json`
