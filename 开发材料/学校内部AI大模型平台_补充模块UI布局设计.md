# 学校内部 AI 大模型平台补充模块 UI 布局设计

> 本文档用于补充「学校内部专用 AI 大模型平台」前端设计方案中的核心功能模块，包括：**提示词中心、知识库、智能体工作台、管理与监控**。内容可直接合并到原 Markdown 设计文档中，建议放置在「模型广场」之后，作为平台核心功能区的深化设计。

---

# 一、提示词中心 Prompt Library

## 1. 页面定位

「提示词中心」是学校内部 AI 平台的高频入口，主要帮助教师、学生和管理人员快速调用经过优化的 Prompt 模板，降低 AI 使用门槛。它不是简单的模板列表，而是一个面向教学、科研、学习、行政管理的“智能任务启动中心”。

页面应体现：

- 模板分类清晰；
- 使用门槛低；
- 可一键调用到 AI 对话；
- 支持收藏、复制、编辑、测试；
- 支持学校沉淀优秀 Prompt 资产。

---

## 2. 提示词中心整体布局

### 推荐采用“三栏式布局”

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部区域：页面标题 / 全局搜索 / 新建提示词 / 分类筛选            │
├───────────────┬────────────────────────────┬─────────────────┤
│ 左侧分类导航   │ 中间提示词卡片列表            │ 右侧预览与快捷使用 │
│ 教学类         │ Prompt Card                 │ 模板详情          │
│ 科研类         │ Prompt Card                 │ 变量填写          │
│ 学习类         │ Prompt Card                 │ 一键发送到对话     │
│ 行政类         │ Prompt Card                 │ 收藏 / 复制 / 编辑 │
└───────────────┴────────────────────────────┴─────────────────┘
```

---

## 3. 顶部区域 UI 设计

顶部区域建议使用白色玻璃拟态卡片，固定在页面上方，保持搜索和新建入口始终可见。

### 内容组成

| 区域 | UI 内容 |
|---|---|
| 左侧标题 | `提示词中心` + 副标题 `沉淀高质量 AI 使用模板，快速启动教学、科研与管理任务` |
| 中间搜索 | 大圆角搜索框，提示语：`搜索教案生成、论文润色、试题设计、学情分析...` |
| 右侧操作 | `新建提示词`、`导入模板`、`我的收藏` 按钮 |

### 视觉建议

- 搜索框使用浅灰底 `#F3F4F6`；
- 新建按钮使用蓝紫渐变；
- 顶部可增加一个小型状态标签：`校内精选 128 个模板`；
- 页面背景保持浅灰白，避免模板过多造成视觉疲劳。

---

## 4. 左侧分类导航

左侧分类导航建议采用「图标 + 分类名称 + 数量」结构。

| 分类 | 图标建议 | 示例内容 |
|---|---|---|
| 教学设计 | BookOpen | 教案生成、课堂导入、教学目标、活动设计 |
| 课件制作 | Presentation | PPT 大纲、页面文案、讲稿生成 |
| 试题与评价 | ClipboardCheck | 试题设计、评分量规、作业反馈 |
| 科研写作 | FileText | 摘要、引言、文献综述、论文润色 |
| 学习辅助 | GraduationCap | 知识点总结、错题解析、笔记整理 |
| 行政办公 | Briefcase | 通知撰写、会议纪要、方案汇报 |
| 我的收藏 | Star | 用户收藏的高频模板 |
| 学校精选 | Sparkles | 平台管理员推荐模板 |

### 交互设计

- 当前选中分类使用淡蓝背景 + 左侧高亮条；
- Hover 时卡片轻微右移 2px；
- 支持折叠为图标模式；
- 分类可显示数量，例如：`教学设计 36`。

---

## 5. 中间提示词卡片区

中间区域是主要内容区，采用卡片网格布局。

### 卡片结构

```text
┌─────────────────────────────┐
│ 图标  提示词标题              │
│ 标签：教学设计 / 教师 / 推荐   │
│ 简短说明：用于快速生成……      │
│ 使用场景：七年级信息科技课     │
│ 适配模型：ChatGPT / Claude    │
│ ─────────────────────────── │
│ 使用次数  收藏数  评分         │
│ [立即使用] [预览] [收藏]       │
└─────────────────────────────┘
```

### 卡片字段建议

| 字段 | 内容说明 |
|---|---|
| 标题 | 如：`生成一份高质量课堂教学设计` |
| 场景标签 | 教学、科研、学习、行政、管理 |
| 适用对象 | 教师、学生、管理员、教研员 |
| 推荐模型 | ChatGPT、Claude、Gemini、Minimax |
| 难度等级 | 入门、进阶、专家 |
| 使用次数 | 体现模板热度 |
| 评分 | 体现模板质量 |
| 操作按钮 | 立即使用、预览、复制、收藏、编辑 |

### 视觉风格

- 卡片圆角建议 `20px`；
- 卡片默认白底，Hover 出现轻微阴影和蓝色描边；
- 推荐模板可在右上角加 `精选` 小标签；
- 热门模板可增加微弱金色角标；
- 每张卡片图标使用不同柔和底色，增强识别度。

---

## 6. 右侧提示词预览面板

右侧面板用于展示选中 Prompt 的完整信息，并支持一键使用。

### 面板内容

| 模块 | UI 内容 |
|---|---|
| 模板标题 | 提示词名称、收藏按钮、编辑按钮 |
| 模板说明 | 适用场景、使用建议、输出目标 |
| 变量填写 | 课程名称、年级、主题、输出格式、字数要求 |
| Prompt 正文 | 可折叠代码块，支持复制 |
| 输出示例 | 展示 AI 生成效果预览 |
| 操作按钮 | `一键发送到对话`、`复制提示词`、`保存为我的模板` |

### 变量填写设计

建议采用表单卡片形式，例如：

```text
课程名称：信息科技
年级：七年级
主题：生成式 AI 的基本概念
输出格式：表格 + 教学活动流程
语言风格：严谨、清晰、适合课堂使用
```

用户填写变量后，系统自动拼接 Prompt，减少新手使用难度。

---

## 7. 提示词编辑 / 新建页面

新建提示词页面建议采用「左侧编辑 + 右侧测试」布局。

```text
┌──────────────────────────────┬──────────────────────────────┐
│ 左侧：Prompt 编辑器            │ 右侧：测试运行与输出预览        │
│ 标题 / 分类 / 标签             │ 模型选择                       │
│ 变量设置                       │ 测试输入                       │
│ Prompt 正文编辑                │ AI 输出结果                    │
│ 输出格式要求                   │ 质量评分 / 保存版本             │
└──────────────────────────────┴──────────────────────────────┘
```

### 必备功能

- 支持变量占位符，例如 `{课程名称}`、`{年级}`、`{输出格式}`；
- 支持版本管理；
- 支持管理员审核；
- 支持公开到学校模板库；
- 支持设为个人私有模板；
- 支持运行测试，避免无效 Prompt 进入模板库。

# 二、知识库 Knowledge Base

## 1. 页面定位

「知识库」是学校内部 AI 平台的重要基础设施，用于承载学校制度、课程资料、教学资源、科研文献、学院文档等内容。它决定 AI 回答是否能够结合校内真实资料，避免泛泛而谈。

页面设计应突出：

- 文件上传简单；
- 资料分类清晰；
- 权限边界明确；
- 解析状态可见；
- 检索效果可测试；
- 回答来源可追溯。

---

## 2. 知识库首页布局

推荐采用「左侧知识库树 + 中间文件管理 + 右侧解析与检索测试」布局。

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部：知识库标题 / 搜索 / 上传文件 / 新建知识库 / 权限设置       │
├───────────────┬────────────────────────────┬─────────────────┤
│ 左侧知识库树   │ 中间文件列表与统计            │ 右侧详情与检索测试 │
│ 学校制度库     │ 文件表格 / 卡片               │ 文件解析状态       │
│ 课程资料库     │ 上传进度                     │ 分段情况           │
│ 科研文献库     │ 命中测试                     │ 权限范围           │
│ 学院文档库     │                              │ 试问一下           │
└───────────────┴────────────────────────────┴─────────────────┘
```

---

## 3. 顶部功能区设计

### 顶部统计卡片

在知识库页面顶部可设置 4 个小型数据卡片：

| 卡片 | 显示内容 |
|---|---|
| 文档总数 | 当前知识库内文件数量 |
| 已解析文档 | 成功完成向量化的文件数量 |
| 今日检索次数 | AI 调用知识库的次数 |
| 权限组数量 | 当前知识库授权范围 |

### 顶部操作按钮

| 按钮 | 功能 |
|---|---|
| 上传文件 | 支持 PDF、Word、PPT、Excel、图片 |
| 新建知识库 | 创建课程、学院、项目等知识库 |
| 批量导入 | 上传文件夹或压缩包 |
| 权限管理 | 设置教师、学生、学院、部门访问权限 |
| 检索测试 | 用问题测试知识库命中效果 |

---

## 4. 左侧知识库树

左侧用于展示不同知识库空间。

### 推荐分类

| 知识库 | 说明 |
|---|---|
| 学校制度库 | 学校规章制度、通知文件、流程规范 |
| 教学资源库 | 教案、课件、课程标准、教材内容 |
| 科研文献库 | 论文、项目材料、研究报告 |
| 学院文档库 | 各学院内部文件、专业培养方案 |
| 行政办公库 | 通知、会议纪要、工作方案 |
| 个人知识库 | 用户个人上传资料，仅自己可见 |
| 课程知识库 | 按具体课程建立资料空间 |
| 智能体绑定库 | 专门用于智能体调用的知识库 |

### UI 设计

- 每个知识库前使用图标；
- 显示文档数量和更新时间；
- 私有知识库加锁形图标；
- 共享知识库显示多人图标；
- 当前选中项采用浅蓝背景和主色文字。

---

## 5. 中间文件管理区

中间区域建议支持「表格视图」和「卡片视图」切换。

### 表格字段建议

| 字段 | 内容 |
|---|---|
| 文件名 | 文件名称与文件类型图标 |
| 类型 | PDF / Word / PPT / Excel / Image |
| 上传者 | 教师、管理员或学生 |
| 所属知识库 | 文件归属 |
| 解析状态 | 解析中、已完成、失败、待审核 |
| 分段数量 | 文档被切分的知识片段数 |
| 权限范围 | 仅本人、课程成员、学院、全校 |
| 更新时间 | 最近更新日期 |
| 操作 | 预览、重解析、移动、删除、权限 |

### 文件状态视觉

| 状态 | 视觉设计 |
|---|---|
| 已完成 | 绿色标签 `已完成` |
| 解析中 | 蓝色进度条 + Loading |
| 待审核 | 金色标签 `待审核` |
| 解析失败 | 红色标签 `失败` + 重试按钮 |
| 权限受限 | 灰色锁形标签 |

---

## 6. 右侧详情与检索测试面板

右侧面板用于展示选中文件或知识库的详细信息。

### 文件详情

| 模块 | 内容 |
|---|---|
| 文件基础信息 | 文件名、大小、上传人、上传时间 |
| 解析状态 | 是否完成 OCR、文本提取、分段、向量化 |
| 分段预览 | 展示若干知识片段 |
| 引用记录 | 最近被哪些对话引用 |
| 权限范围 | 哪些角色可检索该文件 |
| 操作 | 重新解析、下载、删除、修改权限 |

### 检索测试

右侧底部加入一个小型测试框：

```text
试问一下：
[ 输入问题：这门课的教学目标是什么？ ]

命中结果：
1. 《课程标准》第 3 页，相关度 92%
2. 《教学设计》第 5 段，相关度 87%
3. 《课堂活动方案》第 2 页，相关度 81%
```

该模块能够帮助管理员和教师判断知识库是否真的可用。

---

## 7. 知识库上传弹窗设计

上传弹窗建议采用分步式设计：

```text
Step 1：选择文件
Step 2：选择知识库归属
Step 3：设置权限
Step 4：解析与向量化
Step 5：完成并测试
```

### 上传弹窗 UI

- 支持拖拽上传；
- 支持批量上传；
- 显示文件类型限制；
- 显示上传进度；
- 支持上传后自动解析；
- 允许用户选择是否立即开放给 AI 使用。

# 三、智能体工作台 Agent Workspace

## 1. 页面定位

「智能体工作台」用于创建、配置、测试和发布学校内部 AI 智能体。它是模型、提示词、知识库、工具调用和权限控制的组合中心。

典型智能体包括：

- 教案生成助手；
- 论文润色助手；
- 学情分析助手；
- 班主任事务助手；
- 科研文献助手；
- 行政公文助手；
- 新生问答助手；
- 学校制度咨询助手。

---

## 2. 智能体工作台首页布局

推荐采用「智能体卡片广场 + 快捷创建入口」布局。

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部：智能体工作台 / 搜索 / 新建智能体 / 模板创建 / 发布审批     │
├──────────────────────────────────────────────────────────────┤
│ 数据概览：智能体总数 / 已发布 / 待审核 / 今日调用 / 平均评分      │
├──────────────────────────────────────────────────────────────┤
│ 智能体分类 Tabs：全部 / 教学 / 科研 / 学习 / 行政 / 我的          │
├──────────────────────────────────────────────────────────────┤
│ 智能体卡片网格                                                   │
│ Agent Card / Agent Card / Agent Card / Agent Card              │
└──────────────────────────────────────────────────────────────┘
```

---

## 3. 智能体卡片设计

### 卡片结构

```text
┌──────────────────────────────┐
│ 图标 / 智能体名称 / 状态标签   │
```

### 卡片字段

| 字段 | 内容 |
|---|---|

| 操作按钮 | 开始使用、编辑、复制、停用 |

## 4. 新建智能体页面布局

新建智能体建议采用「左侧配置导航 + 中间配置表单 + 右侧实时测试」结构。

```text
┌───────────────┬────────────────────────────┬─────────────────┐
│ 配置步骤       │ 配置内容                     │ 实时测试          │
│ 1 基础信息     │ 名称、头像、简介、分类         │ 对话测试窗口       │

│ 3 提示词设定   │ 角色设定、任务边界、输出格式   │ 测试 Prompt        │
│ 4 知识库绑定   │ 选择可调用知识库               │ 查看引用来源       │
│ 5 工具权限     │ 文件、导出、联网、代码解释     │ 工具调用测试       │

│ 7 发布设置     │ 可见范围、审核流程、版本说明   │ 发布预览           │
└───────────────┴────────────────────────────┴─────────────────┘
```

## 5. 智能体配置面板

### 5.1 基础信息

| 字段 | UI 形式 |
|---|---|
| 智能体名称 | 输入框 |
| 智能体分类 | 下拉选择：教学、科研、学习、行政 |
| 智能体头像 | 图标选择器或上传图片 |
| 简介 | 多行文本 |
| 使用对象 | 教师、学生、管理员、全校用户 |
| 可见范围 | 私有、课程内、学院内、全校 |

### 5.2 模型选择

此处与「模型广场」联动，支持选择：

- ChatGPT；
- Claude；
- GPT-image 生图；
- Gemini；
- Minimax；
- 学校私有模型；
- 本地部署模型。

UI 建议使用模型选择卡片：

```text
[ ChatGPT     通用能力强      选择 ]
[ Claude      长文本与写作强   选择 ]
[ Gemini      多模态理解强     选择 ]
[ Minimax     中文对话友好     选择 ]
[ GPT-image   图像生成         选择 ]
```

选中模型后，右侧显示该模型的能力标签、适用任务、限制说明。

### 5.3 系统提示词设定

系统提示词编辑器建议使用代码编辑器风格卡片，支持变量。

```text
你是一名专业的{学科}教师，正在帮助{年级}学生学习{主题}。
请按照以下要求输出：
1. 语言适合学生理解；
2. 内容准确；
3. 给出课堂活动建议；
4. 避免生成不符合学校规范的内容。
```

支持功能：

- 一键插入变量；
- 从提示词中心导入；
- 保存为模板；
- 版本对比；
- 运行测试。

### 5.4 知识库绑定

绑定知识库时，采用多选卡片：

| 知识库 | 说明 | 权限 |

## 6. 右侧实时测试窗口

右侧测试窗口类似小型 AI 对话框。

### 设计内容

- 顶部显示当前智能体名称；
- 中间是测试对话；
- 底部输入测试问题；
- 回答后显示：

  - 回答耗时；
  - Token 消耗。

这样管理员或教师可以在发布前验证智能体效果。

# 四、管理与监控 Admin & Monitoring

## 1. 页面定位

「管理与监控」是平台管理员、信息中心、学院管理人员使用的后台中枢，主要用于管理用户、权限、模型、知识库、智能体、安全审计和使用数据。

设计目标：

- 数据清晰；
- 风险可见；
- 权限可控；
- 成本可监测；
- 使用情况可追踪；
- 支持学校内部管理流程。

# 五、四个模块之间的产品联动关系

这几个模块不是孤立页面，而应形成完整闭环。

```text
提示词中心
   ↓
帮助用户快速发起高质量 AI 任务

知识库
   ↓
为 AI 回答提供校内可信资料来源

智能体工作台
   ↓
把模型、提示词、知识库、工具能力组合成专属助手

管理与监控
   ↓
统一管理用户、权限、成本、安全与运行状态
```

最终形成：

> 用户通过提示词快速提出任务，AI 基于知识库生成可信回答，智能体将高频任务产品化，管理与监控保障平台安全、稳定、可持续运行。
