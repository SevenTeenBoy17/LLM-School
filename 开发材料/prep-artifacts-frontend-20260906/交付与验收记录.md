## 已打通的前端操作

- 共备：检索筛选、日常 / 研究课、新建私有草稿、归档恢复、底稿编辑、讨论回应及处理理由、观察记录、复盘、修订历史、个人改编、完整 JSON 备份恢复。
- 未提交的意见、回应、处理理由均参与未保存保护；SPA 离开后按账号、项目及完整保存基线恢复内存缓冲。实际刷新仍需先保存或导出备份。
- 产物：列表 / 缩略图切换、筛选排序、批量整理与删除确认、UTF-8 Markdown / 文本导入、学生正文与教师备注分离、版本切换、人工审阅、演示分享 / 撤回。
- 编辑新版本会清空本版本审阅状态；分享每次重新确认，仅冻结学生正文快照，不含教师备注。
- 导出生成真实 Markdown / ZIP 文件；200 文件批次实测停止、收起、重开、继续。进度由实际已完成文件数驱动。
- GSAP 弹窗进入动效与上下文清理，支持减少动态效果设置、键盘焦点约束、Escape 与焦点返回。

## 明确边界

本轮不接新增后端。共备成员、团队讨论、共享快照都是有明确标识的本机演示；不会邀请或通知成员，不会实际发布给学生。不虚构在线 AI、课堂证据或团队共识。

本机状态按已认证账号与会话版本隔离，仅存当前标签页 sessionStorage。身份切换或核对失败先锁定工作区；损坏的存储原文保留，不被示例覆盖。存储不可用时明确提示仅保留页面内存。

“我的归档”仍读取原有真实接口，真实发布 / 删除有单独新确认。本轮没有执行真实发布或删除；隔离数据库为空时，仅用标注的只读接口契约样例验证预览及取消确认，不能替代后端发布验收。

相对画布的功能取舍：正文用结构化编辑而非完整富文本编辑器；课件缩略图是实际内容提纲，不冒充已生成高保真 PPT；当前导出是 Markdown / ZIP，不是 DOCX / PPTX。AI 改进建议按钮在模型和处理位置未确定时禁用。
