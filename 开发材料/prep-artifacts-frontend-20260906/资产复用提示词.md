# 资产复用规格

以下为按本轮已生成素材反向整理的复用规格，不是对原始工具提示词的逐字记录。

## 共用提示词

为学校教师工作平台制作一组清晰、专业、现代的浅浮雕陶瓷质感图标。钴蓝、青蓝、白色作为主体，少量暖黄点缀；圆润但克制的外形、轻微倒角、高光和接触阴影，简洁易识别，不要高反光塑料、过度立体玩具感、发光星云、装饰散点或机器人。前视略带透视，全部主体完整展示，统一视觉体积和光源。纯 #00FF00 背景，各主体留足隔离边距，不使用绿色主体或绿色反射，方便抠图。不要文字标题、品牌水印、边框或卡片背景，不要把按钮 UI 画入素材。

## 八项主题

1. 共备：打开的白色手册、蓝色书脊与书写笔，页面上一个水滴主题标记。
2. 教学产物：蓝色材料收纳盒，整齐可见的白色文档页。
3. 校园节水：结构清楚的蓝色水龙头和一滴水。
4. 光合作用：两片青蓝叶的幼苗，简单短底座，避免纯绿和荧光绿。
5. 数学：白色方程演示板、蓝色边框，极简数学记号。
6. 阅读：打开的书，白色书页、浅蓝与少量淡紫书边。
7. 学习单：白色夹板与蓝色书写笔，短行线提示文本结构。
8. 课题归档：打开的蓝色文件夹与白色文档。

## 处理与落位

- 原始图集保留；基于绿色超出红蓝通道的部分建立透明度并抑制绿色边缘，再按主体边界裁切。
- 输出统一 256×256 RGBA PNG，主体完整，有透明留白；当前 UI 最大常用尺寸 64px。
- 统一容器大小和 object-fit，图标不因 hover、标签或加载状态挤压文字。
- 搜索、关闭、保存、下载、箭头等动作使用现有可访问组件与 Lucide 图标，不用图片代替交互控件。
- 实际文件、检查图与处理脚本见交付记录。资产没有宣称为 4K 单图；以实际输出尺寸为准。
