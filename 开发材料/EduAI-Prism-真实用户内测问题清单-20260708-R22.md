# EduAI Prism 真实用户内测问题清单 - R22

## R22-AGENT-GOV-001

级别：P1  
状态：已修复并复测通过  
问题：教师创建的草稿智能体、提交审核后的智能体，学生仍能在列表、详情和 `?use=1` 使用入口访问。  
影响：未完成/未审核智能体会提前暴露给学生，破坏学校内部发布治理，也会让未审提示词和知识库绑定被直接使用。  
修复：统一智能体可见性契约：管理员和创建者可读；普通非创建者只可读 `pub`；`?use=1` 复用可见性并拒绝停用态。  
证据：`r22-postfix-api-setup.json`、`r22-postfix-disable-boundary-cleanup.json`。

## R22-AGENT-GOV-002

级别：P1  
状态：已修复并复测通过  
问题：管理员 `/admin/agents` 能看到待审核智能体，但没有真实可用的审批/退回/停用动作。  
影响：真实学校内测中，管理员无法完成“教师提交 -> 管理员审批 -> 学生可用”的闭环，只能查看状态，留存和治理体验都会受损。  
修复：表格新增真实治理动作，等待 PATCH 返回后更新本地行状态和状态提示。  
证据：浏览器真实点击“通过发布”“停用”，学生端 API 读回通过。

## R22-AGENT-GOV-003

级别：P2  
状态：已修复并复测通过  
问题：全局搜索的智能体查询只排除了 `disabled`，存在返回草稿/审核态智能体的绕过风险。  
影响：即使列表和详情修复，搜索结果仍可能暴露未发布智能体名称与描述。  
修复：搜索仅返回 `status='pub'` 的智能体。  
证据：代码审查定位 `app/lib/server/db.ts` 查询已收紧；整体边界复测无 R22 泄露。

## R22-AGENT-GOV-004

级别：P2

问题：新增后台治理按钮若沿用小表格按钮尺寸，移动端或紧张审核场景触控余量不足。  
修复：新增治理动作按钮最小高度统一为 42px。  
证据：最终浏览器复核全部治理按钮高度为 42px，控制台错误 0。
