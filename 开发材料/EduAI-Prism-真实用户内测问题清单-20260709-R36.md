# EduAI Prism 真实用户内测问题清单 R36

## 已修复

### R36-KB-MOB-001 P2：知识库移动端触控目标不足

- 现象：真实移动端打开 `/knowledge` 后，表格/卡片切换、上传文件、文件行选择、删除按钮、安全求助入口等可见控件低于 40px。
- 修复：知识库页、上传弹窗和安全求助入口改为显式 `40px` 触控约束，避免项目根字号缩放导致 `min-h-10` 实际只有约 35px。
- 验证：最终脚本返回 `mobileSmallTargets=[]`，无横向溢出。

### R36-QA-001 P3：测试脚本把查询词回显误判为隐私泄漏

- 现象：学生搜索教师私有文件时，页面正常显示查询词和 `0 条命中`，脚本却因正文含查询词而判失败。
- 修复：脚本改为判断私有文件名/命中片段是否出现，并要求显示清晰 0 命中状态。
- 验证：最终学生私有搜索 API 返回 `hits: []`，UI 显示 0 命中；无文件名泄漏。
