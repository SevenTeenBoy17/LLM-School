## R42-CI-001 - 会话历史缺少可见重命名入口

严重级别：P2  
影响范围：教师会话管理、历史会话整理、长时间使用留存  
状态：已修复

### 复现方式

教师进入 AI 对话，创建新会话并等待 AI 返回后，尝试在历史会话列表中整理会话标题。测试发现没有稳定可见的重命名入口，真实用户只能依赖自动标题，难以在多次教研、班会、家校沟通材料生成后快速回找。

### 根因判断

历史会话列表此前只有置顶、删除等动作，缺少与已有 `/api/chat/sessions` PATCH 能力对应的 UI 入口。产品能力在接口层部分存在，但用户路径没有闭合。

### 修复方案

- 在 `ChatSidebar` 中新增内联重命名状态。
- 当前会话或 hover/focus 状态下显示编辑按钮。
- 重命名时显示输入框、保存、取消。
- 保存后调用页面层 `handleRename()`，复用现有会话 PATCH API。
- 成功后本地会话列表即时更新。

### 复验结果

最终真实使用脚本通过 UI 执行重命名，服务端读回标题为：

`R42CI_MRDQCX7B renamed chat session`

判定：通过。

## R42-CI-002 - 学生可对教师消息提交反馈

严重级别：P1  
影响范围：权限边界、数据可信度、教师会话隐私  
状态：已修复

### 复现方式

教师生成 AI 回复后，学生使用该教师消息的 `messageId` 调用反馈接口。基线测试中接口返回成功，学生可以写入不属于自己的消息反馈。

### 根因判断

反馈接口只验证登录状态，没有验证 `messageId` 是否属于当前用户的会话。任何已知消息 ID 都可能被越权写入反馈。

### 修复方案

- 在 `app/lib/server/db.ts` 新增 `messageBelongsToUser(userId, messageId)`。
- 在 `app/app/api/chat/feedback/route.ts` 写入反馈前执行归属校验。
- 非本人消息统一返回 `404 { error: "not_found" }`，避免暴露资源存在性。

### 复验结果

学生对教师消息提交反馈最终返回：

`404`

教师本人反馈闭环仍正常：

- 点赞返回 `200`，读回 `up`
- 点踩返回 `200`，读回 `down`
- 清除返回 `200`，读回已删除

判定：通过。

## R42-CI-003 - 学生可收藏教师消息并造成收藏泄漏

严重级别：P1  
影响范围：跨用户数据隔离、收藏列表可信度、隐私安全  
状态：已修复

### 复现方式

教师生成 AI 回复后，学生使用该教师消息的 `messageId` 调用收藏接口。基线测试中接口返回成功，且学生收藏列表可读到该教师消息引用。

### 根因判断

收藏接口此前没有按资源类型做归属判断。`kind=message` 和 `kind=session` 的收藏需要服务端确认目标确实属于当前用户。

### 修复方案

- 在 `app/app/api/favorites/route.ts` 新增 `canTouchFavoriteTarget()`。
- `kind=message` 时使用 `messageBelongsToUser()` 校验消息归属。
- `kind=session` 时使用 `getSession(userId, sessionId)` 校验会话归属。
- 越权收藏和删除统一返回 `404`。

### 复验结果

学生收藏教师消息最终返回：

`404`

学生收藏列表读回：

`favoritesLeak=false`

教师本人收藏闭环仍正常：

- 收藏开启返回 `201`
- 会话读回包含当前消息 ID
- 取消收藏返回 `200`
- 会话读回不再包含当前消息 ID

判定：通过。

## R42-CI-004 - 聊天页部分按钮和触控目标偏小

严重级别：P2  
影响范围：移动端可用性、误触率、真实用户连续操作体验  
状态：已修复

### 复现方式

在桌面和移动端扫描聊天页真实结果状态，部分消息操作、顶部栏按钮、移动端历史操作按钮和输入区按钮低于稳定点击尺寸。

### 根因判断

聊天页的操作按钮由多个组件分散实现，历史上以视觉紧凑为主，没有统一落到移动端和桌面端都稳定的最小交互目标。

### 修复方案

修复范围：

- `MessageBubble.tsx`：消息操作和导出菜单项提升到稳定尺寸。
- `ChatTopbar.tsx`：模型、知识库、深度思考、收藏、复制、更多、导出等按钮统一尺寸。
- `Composer.tsx`：发送按钮和工具按钮统一尺寸。
- `ChatSidebar.tsx`：侧边栏会话行、置顶、重命名、删除、保存、取消按钮统一尺寸。
- `chat/page.tsx`：移动端新建、最近会话、历史操作按钮统一尺寸。

### 复验结果

最终真实使用脚本输出：

- 桌面端：`smallTargets=[]`，`overflowX=false`
- 移动端：`smallTargets=[]`，`overflowX=false`

判定：通过。
