# EduAI-Prism 真实用户内测问题清单 R44

## 已修复

### R44-ANALYTICS-001 P1 后台分析活跃账号口径错误

现象：管理员接口内容审阅发现 `近 7 日活跃账号=5`，但真实用户表只有 `4` 个账号。  
原因：活跃用户聚合直接统计历史审计表中的 `userId`，包含已经清理的临时测试用户。  
修复：活跃账号统计限定在当前 `users` 表内，通过 `EXISTS` 关联近期会话、审计和智能体创建记录。  
验证：最终 API 返回 `近 7 日活跃账号=4`、`全量 4 个账号`。

### R44-ANALYTICS-002 P2 移动/窄视口触控目标不足

现象：Browser DOM 测得分析页刷新按钮和顶栏图标按钮约 `42px`，低于 44px 可点击基线。  
原因：原来的 `h-12/w-12` 受全局字号影响，实际测量没有达到预期 48px。  
修复：分析页操作按钮与共享顶栏图标按钮改为固定 `48px`。  
验证：最终 Browser 回归中 `smallEnabledButtons=[]`，无横向溢出。
