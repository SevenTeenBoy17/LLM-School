## R2-AI-001 - 教师普通教学问题误走学生式学伴兜底

严重级别：P1

影响范围：`/api/chat` 在未配置 `ANTHROPIC_API_KEY` 的本地兜底路径；教师、科研、管理等非学生角色的普通问题。

复现证据：

- 请求角色：teacher
- 请求：`请为初三物理“电路故障分析”生成一段 8 分钟课堂导入，包含一个提问和一个板书标题。`
- 修复前返回：`我先和你一起把它理清楚`、`拆成小步`、`写下你的思路或尝试` 等学生学伴语气。
- 证据文件：`round2-api-ai-security.json`

根因：

- `D:\VB\LLM-School\app\lib\server\llm.ts` 的 `localReply()` 对所有普通角色共用学生式思考框架，没有按 `user.role` 分支。

修复：

- `teacher` 返回可直接试用的课堂导入、板书标题、课堂提问。
- `researcher` 返回研究设计框架、指标、伦理隐私提醒。
- `admin` / `college-admin` 返回管理侧审计日报/治理清单。
- `student` 仍保留学伴式分步引导。
- `softConcern()` 仍保持最高优先级。

复测证据：

- `postfix-targeted-regression.json`
- `round2-api-ai-security-after-fixes.json`
- 教师响应包含 `课堂导入`、`板书标题`、`课堂提问`，不再出现 `拆成小步`、`你的想法` 等学生化提示。

## R0-ENV-001 - 生产启动必须配置 `EDUAI_SESSION_SECRET`

严重级别：P1 环境前置项

影响范围：生产模式 `next start`。

现象：

- 本轮第一次以生产构建启动 `:3420` 时，登录 API 因缺少 `EDUAI_SESSION_SECRET` 返回 500。
- 这是安全 fail-fast 设计，不是要绕过的代码缺陷。

处置：

- 本轮 QA 使用仅进程生效的随机测试密钥继续验证，没有写入 `.env.local` 或任何私密文件。
- `D:\VB\LLM-School\app\.env.example` 已明确写明生产必填和生成方式：`openssl rand -base64 48`。

建议：

- 部署/启动说明中继续强调：生产或演示生产构建必须设置 `EDUAI_SESSION_SECRET`。
- 登录 UI 可以在 500 时展示“平台配置异常，请联系管理员”而不是泛化为“账号或密码不正确”；这属于体验增强，不影响本轮功能验收。
