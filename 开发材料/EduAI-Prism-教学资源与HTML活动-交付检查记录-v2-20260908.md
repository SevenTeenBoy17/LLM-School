## 发现与修复

1. 账户受导航内容高度牵引：改为中段弹性滚动、上下固定区；初始相同测试红灯 29 项，修复后绿灯。后续只强化移动断点等待，未放宽几何阈值。
2. HTML 分类可人为改成“教案”，下载提醒因此误判：按文件扩展名判断，保留安全警示，已用真实下载回归。
3. 新 AbortSignal 组合 API 兼容性：采用可取消控制器与明确 8 秒超时，删除新 API 后仍实际运行成功。
4. CSP 预检和浏览器的解释不一致：重复指令、扩展覆盖指令、非 ASCII 空白均拒绝；只接受约定指令和值。新增本地负向控制，未向真实外部服务发送攻击探针。
5. 运行壳按字符而非字节限长：追加 UTF-8 编码字节限制，与 5 MB 资源上限一致。
6. 同 HTML 不同任务可能共享笔记：按包身份隔离，普通文件与活动包使用互斥命名空间，并验证旧记录的资源摘要/包身份。
7. 未保存笔记刷新或点击链接会直接丢失：增加关闭、当前文档导航链接和原生 beforeunload 提醒；不承诺系统强杀或崩溃恢复。
8. 校园 HTTP 缺少 Web Crypto 时异常不清晰：教师上传、活动运行、学生导入/示例均给出 HTTPS 环境提示。
9. 学生旧格式预览提示“下载”但没有入口：补原文件下载按钮，DOC/PPT 下载与原字节一致。
10. 媒体 StrictMode 清理后源地址未恢复：专项实现修复并检查播放进度、关闭暂停和 Blob 清理。

测试自身发现的严格定位器歧义、错误文案假设和响应式瞬时采样已按真实语义修正；失败记录保留。没有删除原有并发、事务中止、账号隔离或容量上限断言。旧 HTML “拒绝”断言改为有条件接受，是本次需求的明确变更，不是偷偷放宽安全要求。
