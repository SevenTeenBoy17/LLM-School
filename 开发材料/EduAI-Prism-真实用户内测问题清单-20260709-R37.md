# EduAI Prism 真实用户内测问题清单 R37

## 已修复

### R37-KB-MOB-001 P1：移动端上传弹窗底部按钮不可达

- 现象：390x844 移动端选择文件后，上传弹窗高度超过视口，“下一步”按钮位于可点击区域外，真实用户流程卡死。
- 修复：上传弹窗增加移动端最大高度、内部滚动、紧凑 padding、文件列表滚动和 sticky 底部操作条。
- 验证：最终脚本在移动端完成“选文件 -> 下一步 -> scope 选择 -> 开始上传 -> 上传完成 -> 完成”全流程。

### R37-KB-MOB-002 P2：卡片视图删除按钮宽度不足

- 现象：移动端卡片视图“删除”按钮高度 40px，但宽度约 37.5px。
- 修复：增加 `min-w-[40px]`。
- 验证：最终移动端触控检查 `smallTargets=[]`，并真实点击该按钮，页面返回 `已删除该文件`。

### R37-QA-001 P3：预期非法输入 400 被误计入异常 console

- 现象：边界测试故意触发 400 Bad Request，浏览器 console 记录预期资源错误。
- 修复：脚本将预期 400/401/403/404 边界请求从“意外 console 错误”中过滤，但仍保留状态码和响应体作为证据。
- 验证：最终脚本 `issues=[]`，非法输入仍明确返回 `400 invalid_input`。

## 通过项

- 未登录列表/搜索/上传均返回 `401 unauthenticated`。
- 非法空文件名、非法 scope、超大文件、超长文本均返回 `400 invalid_input`。
- 教师移动端上传学部共享文件后，教师/学生/管理员均能搜索到真实 token 和片段。
- 学生详情 `200`，管理员详情 `200`。
- 学生非 owner 删除返回 `404 not_found`。
- 教师移动端卡片删除成功，清理后搜索 `hits=[]`。
- `lint`、`typecheck`、`build`、Playwright、code-review-graph、手工审阅均通过。

## 遗留风险

- 当前工作区不是 git 仓库，无法生成 git checkpoint 或 diff-based review；本轮使用 supervisor 证据、Playwright 日志、code-review-graph 和手工审阅替代。
- 本轮未覆盖二进制文件内容解析，因为当前产品合同明确二进制仅按文件名检索；后续若接入 PDF/Word OCR，应另开文件解析质量专项。
