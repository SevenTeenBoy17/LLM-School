# 源码共享说明

## 发布策略

此仓库为当前工程的干净源码快照。原电脑的 Git 历史包含曾被跟踪的数据库备份，因此不直接推送该历史；原工作目录、未提交修改和本地数据均保留。

上传：页面、API、组件、业务模型、数据初始化与迁移、测试源码、依赖锁文件、部署模板、运行资产及设计文档。

不上传：真实密钥及 `.env.local`、SQLite 数据与备份、上传文件、浏览器会话、工具运行记录、依赖安装目录、编译目录、压缩快照、第三方程序/缓存/SWF、已隔离的研究参考素材。历史报告所引用的本地截图与运行日志不随源码公开分发。

## 运行边界

- 本机演示初始化使用合成学生/教师/管理员数据，真实 AI 服务按部署方配置。
- 生产空库支持初始管理员。真实用户批量导入在当前界面仍不可用，需补齐账号接入后才可正式校内试用。
- SQLite 与文件存储仅适用于单校、单实例、有持久化磁盘的部署，不适合直接无服务器化或多副本扩容。
- 模型和图片资产中有尚需补齐许可复核的历史条目，详见 `app/public/art/REGISTRY.md`。私有协作不代表已授予公开再分发许可。
- 校内资源库当前为前端体验、本机草稿和示例资源，学校共享服务器尚未接入；管理员权限页也包含已标明的界面示例数据。
- 原有设计方案、历史评审与本次源码共享验证是不同层次的证据，不据此宣称全部业务、性能或安全测试通过。

## 安全补丁

此次共享准备发现并修补了依赖告警：Next.js / eslint-config-next 16.3.2→16.3.3，Sharp 0.35.3→0.35.4，及兼容版本范围内的 xmldom、fflate、js-yaml。锁文件由 npm 重新生成并通过干净安装；未执行强制跨大版本升级。

依据：[Next.js Windows 公告](https://github.com/advisories/GHSA-p293-qw3h-jr36)、[图像优化公告](https://github.com/advisories/GHSA-2xp9-vwfh-vxw4)、[Sharp 公告](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c)。

原电脑上先前启动的旧服务没有被替换；仓库和依赖锁已更新，原工作目录需重新安装依赖并重建、重启后才运行补丁版本。
