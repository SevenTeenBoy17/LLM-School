# Reference Register

The source application was inspected in a signed-in QQNCmini session without purchases, claims, harvesting, friend access, or other resource-changing actions.

Observed states:

1. Main isometric scene and persistent HUD.
2. Top system flyout.
3. Left activity flyout.
4. Tool tray.
5. Backpack-style lower overlay.
6. Warehouse-style centered modal.
7. Seasonal event modal.
8. Locked and actionable scene nodes.

Proprietary screenshots and source assets are intentionally not committed. The implementation baseline is the original EduAI scene recorded in `public/art/manor-v3/manor-world.webp` and the generated Playwright screenshots under `test-results/`.
